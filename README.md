# عاداتي — تطبيق متابعة العادات

## النشر على GitHub Pages (مجاناً)
1. أنشئ حساباً على github.com إن لم يكن لديك.
2. اضغط **New repository**، وسمّه مثلاً `adati`، واجعله **Public**، ثم **Create repository**.
3. اضغط **uploading an existing file** واسحب كل محتويات هذا المجلد (وليس المجلد نفسه) ومنها مجلد `icons`، ثم **Commit changes**.
4. افتح **Settings ← Pages**. في **Branch** اختر `main` ثم المجلد `/(root)` واضغط **Save**.
5. بعد دقيقة أو دقيقتين يظهر رابط التطبيق: `https://اسم-المستخدم.github.io/adati/`

## التثبيت على الهاتف
- **Android (Chrome):** افتح الرابط ← زر «تثبيت التطبيق» داخل الصفحة، أو ⋮ ← «تثبيت التطبيق».
- **iPhone (Safari):** افتح الرابط ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية». ثم افتح التطبيق من الأيقونة واضغط «تفعيل إشعارات التذكير» (يحتاج iOS 16.4 أو أحدث).

## ملاحظات
- البيانات محفوظة على الهاتف نفسه. نزّل نسخة احتياطية من حين لآخر.
- لنقل بياناتك من النسخة القديمة: نزّل منها نسخة احتياطية، ثم «استعادة من نسخة» هنا.
- يعمل بدون إنترنت بعد أول فتح.
- التذكير يصل ما دام التطبيق مفتوحاً أو في الخلفية حديثاً؛ النظام قد يوقفه إذا أُغلق تماماً.
- الإصدار ٢: أنواع عادات (إنجاز، كمية، حد أقصى، نطاق)، ومستويات الحد الأدنى/الهدف/ممتاز، ومجالات، وأفضل سلسلة، وعادات أسبوعية، وعادات جاهزة. يُنقل سجل الإصدار ١ تلقائياً.
- عند تعديل الملفات لاحقاً: غيّر `VERSION` في `sw.js` (مثلاً إلى `adati-v2`) ليحدّث الهاتف النسخة.
